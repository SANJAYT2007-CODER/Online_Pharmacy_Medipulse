# Online Pharmacy Ordering Platform

## 1. Title

**Online Pharmacy Ordering Platform**

## 2. Domain

**E-Commerce / Healthcare Technology**

A web-based platform for browsing, ordering, and managing medicines online.

## 3. Users

### Customer
- Register/Login
- Search medicines
- Add medicines to cart
- Upload prescription
- Place orders
- Track orders

### Admin
- Manage medicines
- Manage categories
- Manage stock
- Manage users
- Manage orders
- Verify prescriptions

### Pharmacist
- Review prescriptions
- Approve/Reject prescriptions
- Process orders

## 4. Problem Statement

Customers usually need to visit pharmacies physically to check medicine availability and purchase medicines. This can be time-consuming and inconvenient. The system provides an online platform where users can search medicines, check availability, upload prescriptions when required, and place orders. Admins and pharmacists can manage medicines, prescriptions, stock, and orders.

## 5. Proposed Solution

The application will provide:

- User registration and login
- Medicine search and filtering
- Medicine details
- Shopping cart
- Prescription upload and verification
- Address management
- Online checkout
- Order tracking
- Admin dashboard
- Medicine and stock management
